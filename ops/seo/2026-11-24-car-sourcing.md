# Car Sourcing 发布验收

- 基线 GitHub main 0bfee6183fef66268b1454e5b029ee4f8a5b6e8e。范围为官网代采购板块，接续 ChatGPT「瓜子二手车代办翻译」。
- 首页导航和内容入口，英文、法语、阿语、俄语、西语页面，无后缀 canonical，语言互链、Service 结构化数据和 sitemap。选车链接由客户提供，未引入车源采集。
- 服务费计算以实际车价乘 5% 并按每台 USD 500 保底。验车基础版 USD 100/次，高级版 USD 200/次，两档均预付且分别预约、派人。基础后再约高级须付完整 USD 200，两次合计 USD 300。首检任选一档，成交只抵扣 USD 100，未成交验车费不退。另行验车及运输、第三方费用和整备另计。
- 同一网站询盘 API、CRM 保存和钉钉通知队列。代采购分类使用 car_sourcing 来源入口；车辆链接字段及留言同步保存；管理员可按来源筛选。
- 本机生产配置构建、126 项 Node 测试、171 HTML/142 sitemap 地址结构检查通过。Chrome 五语言 × 390/1200 CSS 视口共十次布局和费用检查。法语仅邮箱、阿语仅 WhatsApp 提交通过本地实际函数，数据在进程内存中。模拟 Webhook、分配、钉钉送达后归档以及原有详情/WhatsApp 测试通过。
- 发布回退参考基线提交，通过受控回退保留 CRM 现有记录。首个预览发现 Netlify 尾斜杠路径匹配归一化导致重定向循环，移除相关规则后重新验收。部署、公开站验收及线上 CRM 检查另记接续。实体手机及真实通知送达未测试。
